# IR Control Desktop

Aplicativo desktop (Windows) para controle de ar-condicionado por infravermelho.

## Download

Baixe o instalador mais recente na aba **[Releases](../../releases/latest)**:

- `IR Control Desktop-1.0.0-setup.exe` — instalador NSIS, Windows x64

## Observações

- O instalador **não é assinado digitalmente**. O Windows pode exibir o aviso do SmartScreen: clique em "Mais informações" e depois em "Executar assim mesmo".
- Requer Windows 10 ou superior, 64 bits.
- Este repositório distribui apenas o binário. O código-fonte não é público.
